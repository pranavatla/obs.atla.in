# Brag Plan: obs.atla.in

## What is this app?
A public status page that shows uptime, traffic, real visitors, WAF blocks and Bedrock usage for every atla.in site, built from a `status.json` snapshot that a GitHub Action refreshes from CloudWatch every 15 minutes.

## Goal & motto (the user asked for both to be unmistakable)
- **Goal:** one honest status page for every atla.in site. This is the video's hook and the headline of scene 2.
- **Motto:** **"Measured, never simulated."** It's the site's own copy (`index.html` Overview lede), used verbatim. The whole outro is built around it.

## Angle
Most status pages are marketing. This one only shows numbers it actually measured, and when a source fails it says "No data" instead of guessing. The video states the goal, shows what's tracked, shows the pipeline, and lands on the motto.

## Tone
- Preset: polished
- Direction: calm, dark and precise, matching the site's dark theme. Fast cuts with firm holds.
- Format: landscape 1920x1080. Duration: **11s** (user override of the 15–25s default)
