# Brag Plan: obs.atla.in

## What is this app?
obs.atla.in (AtlaOps) is a cloud-ops dashboard where you watch live telemetry, deliberately trigger incidents (traffic spike, DB error burst), and get an AI root-cause analysis from Ops Guru.

## Goal & motto (user asked for these to be explicit)
- **Goal:** practice real incident response — break production on purpose, then understand why it broke.
- **Motto:** **See it. Break it. Explain it.** — maps 1:1 to the product's three pillars: Real-time Metrics → Incident Simulation → AI-Powered RCA.

## The angle
Most dashboards pray nothing breaks. This one has a "DB Error Burst" button. The video is the motto, acted out: healthy dashboard → click → everything goes red → AI explains it.

## Hook (0–2.2s)
"Break production." slams in, then "On purpose." — the goal in four words.

## Key moments
- Healthy KPI strip (SLO Compliance 99.95%, Active Alarms 0, p95 latency) + service health rows, labelled **See it.**
- Cursor clicks **DB Error Burst** → SLO 99.10%, alarms 3, orders-service / payments-worker flip to degraded, labelled **Break it.**
- Incident RCA card types the real backend summary: "Checkout path degradation driven by database timeouts." labelled **Explain it.**

## Outro (7.9–11s)
obs.atla.in gradient wordmark + "See it. Break it. Explain it." + chips: Real-time Metrics · Incident Simulation · AI-Powered RCA.

## User flow worth showing
Dashboard healthy → click "DB Error Burst" → metrics/services degrade → "Generate RCA" → summary appears.

## Tone
- Preset: app-store (with polished restraint)
- Creative direction: crisp product film, motto-as-chapters
- Interpretation: fast snaps between states, each label held ≥0.8s, one idea per scene.

## Format: landscape — 1920x1080
## Duration: 11s (user override of the 15–25s default)

## Visual identity
- Background: #f4f7fb (gradient #f8fafc → #f1f5f9)
- Text: #0f172a / #475569
- Accent: #2563eb → #0f766e gradient (brand h1); danger #dc2626; warning #d97706
- Font: Inter (display + body); numerals tabular
- Strongest element: insight-card KPI strip + gradient wordmark

## Share copy (draft)
obs.atla.in — a cloud-ops dashboard with a "DB Error Burst" button. See it. Break it. Explain it.

## Audio direction
- Role: punchy bed + sparse motion-matched accents
- Music: happy-beats-business-moves-vol-10 (109.96 BPM), started 15s into the track for energy
- Music treatment: 0.35, short fade-in, fade out over last 0.8s
- Music cue guidance (after 15s offset): strong cues at 3.55s (click/break), 5.19s (Explain scene), 7.92s (wordmark)
- Audio-reactive: none (11s is too short to earn it; documented skip)
- SFX: mouse click on button, soft impact + error buzz on break, drop on RCA, bell on wordmark
- Restraint: no SFX per typed character
