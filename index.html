    How this is measured

    Readings travel one route, every 15 minutes. This page only reads the end of it.

    1. SourcesCloudWatch for CloudFront, load balancers, Bedrock and real-visitor monitoring. AWS WAF. Grafana Synthetic Monitoring uptime checks from 3 probes. The gateway's audit log.
    2. Collectorcollect_status.py runs in GitHub Actions every 15 minutes, started by an Amazon EventBridge rule.
    3. SnapshotThe results go into one file, status.json, with the source of every value.
    4. HostingThe snapshot and this page sit in a private S3 bucket behind CloudFront.
    5. This pageReads only the snapshot. It never queries AWS or Grafana, so a page view costs the same however many people visit.
    Real or absent
    A missing value shows as “No reading”. A source that fails is listed at the top of the page, and its numbers are left out.
